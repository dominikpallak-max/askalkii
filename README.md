# FullBright (Fabric 1.21.11)

Budowanie: wejdź na https://fabricmc.net/develop, wybierz 1.21.11 i sprawdź wersje
(yarn / loader / fabric api) -> wpisz je w gradle.properties.
Potem: `gradle wrapper` (raz), `./gradlew build` -> jar w build/libs/.

Użycie:
1. Kontrolki -> klawisz "FullBright" (domyślnie J, zmienisz w Sterowanie).
2. Zakładki: Lista / Dodaj / AutoRynek / Config.
3. Włącz "AutoRynek: ON" w nagłówku, zamknij menu (ESC), otwórz /rynek.
   (W oknie rynku klawisze modów nie działają - włącz przed otwarciem.)
